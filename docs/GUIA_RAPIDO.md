# Guia rápido — versão inicial

1. Abra a aplicação em Chrome ou Edge.
2. Informe o número inicial (use números fictícios durante testes), a quantidade, sete dígitos e duas cópias, quando esses forem os parâmetros desejados.
3. Ajuste posição inicial e calibração X/Y em milímetros somente quando necessário.
4. Gere as etiquetas e confira a folha na pré-visualização. É possível navegar entre as folhas sem renderizar todas simultaneamente.
5. Na etapa de impressão, confirme o papel Carta e a escala 100%; imprima um teste com identificadores fictícios.
6. O programa não tem limite fixo de 100 folhas, mas lotes grandes podem exigir memória e tempo; avalie o equipamento antes de imprimir.

**Aviso:** o código inicial Angular ainda não substitui o software usado no laboratório. Não utilizar com dados institucionais ou etiquetas de pacientes até a validação do sistema e autorização adequada.
